# Keyboard shortcuts

| Key | Action |
| --- | --- |
| `Ctrl+F`, `Ctrl+K`, `/` | focus the search box |
| `Escape` | clear the search |
| `Ctrl+D` | star the current entry (Favourites) |
| `Ctrl+I` | import a file into a word list |
| `Alt+Left` | back to the previous view |
| `Ctrl+,` | preferences |
| `Ctrl+Q` | quit |
